About CLAIMBACK

Product specifications, technical architecture, and student mini-project deliverables.

Project Specifications

CLAIMBACK is a Smart Warranty & Purchase Tracker engineered to maintain local, verifiable records of retail purchases and accurately compute warranty expiry timelines without requiring cloud accounts, external APIs, or recurring fees.

  • Domain: Consumer Electronics & Retail Asset Tracking
  • Storage Mode: Local JSON file (data/products.json) with automatic backup
  • ID Sequence: Formatted auto-incrementing CB-0001
  • Offline Status: 100% self-contained, zero internet dependencies

Dual Implementation Deliverable

To satisfy both modern web application requirements and the Core Java / Swing mini-project PRD specifications, CLAIMBACK includes both:

1. Modern Web Application

Lightweight zero-dependency Node.js HTTP backend, REST API, responsive UI, live date preview, CSV export.

2. Core Java Swing Desktop App

Modular Java code located in java-swing-version/src with MainFrame, ProductService, and WarrantyService.
